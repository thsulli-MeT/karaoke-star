# All The Glows drop-in song files

`All The Glows` is now pre-registered in Side-Chain as a drop-in song entry.

Place these files in this folder so the song can play and load artwork:

- `0 Lead Vocals_01.mp3`
- `1 Instrumental_01.mp3`
- One artwork file (any one of these names):
  - `cover.jpg` / `cover.jpeg` / `cover.png`
  - `All The Glows.jpg` / `.jpeg` / `.png`
  - `ALL THE GLOWS.jpg` / `.jpeg` / `.png`
  - `all-the-glows.jpg` / `.jpeg` / `.png`

Tip: use the provided background image as one of the supported artwork names above.
